## Triết lý & Tầm nhìn Dự án

Hầu hết các nền tảng học AI hiện nay đều quá khô khan (ngập trong công thức toán học trừu tượng hoặc video bài giảng kéo dài hàng giờ). **ORYZO AI LAB** tiếp cận theo một hướng đi hoàn toàn khác:

1. **Trực quan hóa Không gian 3D (Spatial Visualization):** Biến những khái niệm trừu tượng như *GEMM, Tensor Cores, Latent Space, Self-Attention* thành các tạo tác công nghệ 3D (Museum Artifacts) lơ lửng, cho phép bạn xoay 360°, tách lớp (Exploded View) và quan sát dòng chảy xung nhịp dữ liệu.
2. **Cảm giác Tích lũy (Sense of Ownership):** Mỗi ngày một bài học thực hành. Tích lũy kiến thức sẽ dần mở khóa và hoàn thiện một **Bộ não 3D (The Sentient AI Matrix)** của riêng bạn.
3. **Cập nhật Công nghệ Thời gian Thực (Daily AI Radar):** Tích hợp AI Agent tự động cào các GitHub repos hot nhất trong ngày, phân tích điểm đột phá và giao bài tập thực hành vi mô (Micro-challenge) ngay trong ngày.
4. **Ngôn ngữ Thiết kế Tối giản Cao cấp:** Tuân thủ triệt để phong cách **Darkroom Product Editorial** (Walnut Shadow `#100904`, Warm Cream `#ffedd7`, Bark Brown `#382416`, Cork Border `#40372e`) kết hợp với chế độ **Light Gallery** trang nhã.

## Các Tính Năng Nổi Bật Đã Triển Khai

### 1. The 3D Compute Die (Linh kiện Day 01)
- Mô hình 3D bán dẫn nguyên khối với **16 cụm Tensor Cores (ma trận 4x4)** và **4 tháp bộ nhớ HBM3**.
- **Tương tác 3D:** Xoay tự do 360 độ với độ quán tính mượt mà.
- **Tách lớp 3D (Exploded View):** Tách rời đế silicon, nhân tính toán MMU và các tháp bộ nhớ theo trục thẳng đứng.
- **Mô phỏng Lượng tử hóa (Quantization Modes):** Chuyển đổi giữa `FP16`, `INT8`, và `INT4` để quan sát sự thay đổi tần số xung nhịp dữ liệu và độ nén ma trận thời gian thực.

### 2. Trang Học Tập Độc Lập Chuyên Sâu (`/lesson/day-01`)
- Bố cục đọc tập trung (Deep Focus Mode) với thanh đo tiến độ đọc.
- Giảng giải trực quan: Sự khác biệt bản chất giữa CPU vs GPU vs Tensor Cores.
- Phân tích điểm nghẽn **Băng thông bộ nhớ (Memory Bandwidth)** trong quá trình sinh token của LLM.
- **Khu vực Thực hành & Bài tập ở cuối bài:**
  - *Bộ mô phỏng Lab:* Tính toán VRAM thực tế cần thiết cho mô hình 7B, 13B, 70B theo từng mức nén và kiểm tra độ tương thích với GPU cá nhân.
  - *Trắc nghiệm Bản chất Kỹ sư:* Kiểm tra tư duy thực chiến.
  - *Mở khóa Linh kiện:* Tích hợp linh kiện *The Compute Die* vào 3D Matrix sau khi hoàn thành.

### 3. Hệ thống Tự động hóa Daily AI Radar Pipeline
- **GitHub Crawler:** Tự động quét GitHub Search API cho các repos AI hot nhất được cập nhật gần đây (lượt stars cao, topics: `llm`, `ai-agents`, `inference`, `rag`).
- **OpenAI GPT-4o Agent:** Đọc `README.md` của repo đầu bảng và sinh dữ liệu xuất bản có cấu trúc:
  - *Headline & Daily Quote:* Nhận định sắc sảo về thế giới AI hôm nay.
  - *Góc nhìn Kỹ sư:* Lời khuyên thực chiến về tối ưu hóa hệ thống.
  - *Tiêu điểm Repo:* Lý do đột phá + 3 dòng lệnh CLI để clone và test inference nhanh.
  - *Thử thách vi mô:* Đề bài thực hành gắn liền với repo hot.
- **Trang Đài thiên văn AI (`/radar`):** Khám phá toàn cảnh bản tin của ngày, top 5 repos hot, sao chép lệnh terminal 1-click.
- **Modal Popup thông minh:** Tự động mở khi vào trang chủ, không làm bể form trên mọi kích thước màn hình.
- **Chế độ BYOK (Bring Your Own Key):** Nhập OpenAI API Key trực tiếp trên giao diện web, lưu trữ an toàn trong `localStorage` phía client.

### 4. Giao diện Đa Chế độ (Dual Theme)
- **Darkroom Mode (Mặc định):** Đen hạt óc chó ấm `#100904`, chữ kem `#ffedd7`, ánh sáng viền ấm áp.
- **Light Gallery Mode:** Phong cách triển lãm tối giản `#f6f1e8`, chữ espresso `#18120c`, viền cát mịn `#d5c4af`.

## Hướng Dẫn Cài Đặt & Chạy Cục Bộ

### 1. Yêu cầu hệ thống
- **Node.js:** Phiên bản 18.18 trở lên (khuyên dùng Node 20+ hoặc 22+).
- **Trình quản lý gói:** `npm`, `pnpm` hoặc `yarn`.

### 2. Cài đặt các thư viện
```bash
# Clone repository
git clone https://github.com/HuongDS/ai_learning.git
cd ai_learning

# Cài đặt dependencies
npm install
```

### 3. Cấu hình biến môi trường (Tùy chọn)
Tạo file `.env.local` từ mẫu:
```bash
cp .env.example .env.local
```
Điền OpenAI API Key của bạn (hoặc bạn có thể nhập trực tiếp trên giao diện web qua nút **CẤU HÌNH KEY (BYOK)**):
```env
OPENAI_API_KEY=sk-proj-your-api-key-here
```

### 4. Khởi chạy máy chủ phát triển (Dev Server)
```bash
npm run dev
```
Mở trình duyệt tại **[http://localhost:3000](http://localhost:3000)**.

### 5. Biên dịch sản xuất (Production Build)
```bash
npm run build
npm run start
```

## Hướng Dẫn Triển Khai (Deployment)

### Cách 1: Triển khai 1-click lên Vercel (Khuyên dùng)
1. Truy cập [vercel.com](https://vercel.com).
2. Chọn **"Add New Project"** và liên kết với repository `HuongDS/ai_learning`.
3. Trong phần **Environment Variables**, thêm biến `OPENAI_API_KEY` (tùy chọn).
4. Nhấn **Deploy** — Vercel sẽ tự động tối ưu hóa Next.js App Router và WebGL Canvas.

### Cách 2: Triển khai qua GitHub Actions (CI/CD)
Dự án đã tích hợp sẵn workflow tại `.github/workflows/deploy.yml` để tự động kiểm tra code, build và xác thực tính toàn vẹn mỗi khi có commit mới vào nhánh `main`.
